# Worked Examples

These examples show how test cases are scored. Each one walks through a scenario, shows several **illustrative** responses at different score levels, and explains the scores.

> **The responses in these examples were written by the benchmark maintainers to illustrate the rubric. They are not outputs from any real system and are not benchmark results.**

| Example | Concept | Based on |
|---|---|---|
| [Basic recall](basic-recall/README.md) | Explicit recall as a floor, not a ceiling | IDENTITY-001 |
| [Delayed memory](delayed-memory/README.md) | Bringing an old episode forward when it becomes relevant | EPISODIC-001 |
| [Relationship continuity](relationship-continuity/README.md) | Greeting a friend vs. a stranger | RELATIONSHIP-001 |
| [Consequence memory](consequence-memory/README.md) | Neither forgetting a breach nor ignoring a reconciliation | CONSEQUENCE-001 |
| [Contextual memory](contextual-memory/README.md) | Using context to respond well, and calibration | BEHAVIOR-002, CONTEXT-001 |
