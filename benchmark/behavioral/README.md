# Behavioral Continuity

Tests whether remembered information changes behavior without the user explicitly asking for it. This is the core of the memory-continuity thesis.

Concept page: [Memory Retrieval vs. Memory Continuity](../../docs/memory-vs-retrieval.md#behavioral-recall)

| ID | Title | Dimension | Recall | Condition | Difficulty |
|---|---|---|---|---|---|
| [BEHAVIOR-001](BEHAVIOR-001.json) | Avoiding a disliked nickname without being reminded | `behavioral_continuity` | behavioral | new session | medium |
| [BEHAVIOR-002](BEHAVIOR-002.json) | Not giving unsolicited advice after the user asked for none | `behavioral_continuity` | behavioral | context interruption | medium |
