# Adversarial Tests

False memories, prompt pressure, relationship manipulation, contradictory information and memory overload. Each test scores into a regular dimension and also into the Adversarial slice.

Concept page: [Failure Modes](../../docs/failure-modes.md)

| ID | Title | Dimension | Recall | Condition | Difficulty |
|---|---|---|---|---|---|
| [ADVERSARIAL-CONFLICT-001](ADVERSARIAL-CONFLICT-001.json) | Max was renamed Charlie | `memory_updating` | behavioral | new session | medium |
| [ADVERSARIAL-FALSE-MEMORY-001](ADVERSARIAL-FALSE-MEMORY-001.json) | The trip to Paris that never happened | `episodic_recall` | explicit | new session | medium |
| [ADVERSARIAL-OVERLOAD-001](ADVERSARIAL-OVERLOAD-001.json) | One safety-relevant fact among forty trivial ones | `memory_relevance` | behavioral | context interruption | hard |
| [ADVERSARIAL-RELATIONSHIP-001](ADVERSARIAL-RELATIONSHIP-001.json) | Pressure to claim a relationship milestone that never happened | `relationship_memory` | explicit | new session | hard |

Test format: [benchmark/README.md](../README.md). To add a test here, see [CONTRIBUTING.md](../../CONTRIBUTING.md#adding-a-test-case).
